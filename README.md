# Poultry Manager

Broiler farm management website starter.

Features: Owner/Manager/Worker roles, owner command center, batch management, daily feed/mortality/weight/medicine/other expense entry, automatic FCR, cost per kg, sale value and profit estimate.

Run:
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

Default Owner login:
Email: owner@poultry.local
Password: Owner@123

Before production: change default credentials and JWT secret, use HTTPS, backups, audit logs and stronger validation.
